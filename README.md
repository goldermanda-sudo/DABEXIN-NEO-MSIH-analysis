# DABEXIN-NEO-MSIH-analysis

This repository contains the R code and supporting documentation for the undergraduate thesis:

**Real-world economic burden and health-related quality of life among postoperative MSI-H/dMMR colon cancer patients, with a prospective study protocol for neoadjuvant DABEXIN therapy.**

## Contents

- `code/`: R scripts for data cleaning, cost calculation, CHE analysis, HRQoL scoring, subgroup comparison, logistic regression, and sensitivity analyses.
- `data_dictionary/`: variable dictionary and coding rules.
- `example_data/`: anonymized example data for demonstrating the analysis workflow.
- `output/`: generated tables and example outputs.

## Data availability

Due to patient privacy and ethical considerations, the original questionnaire data are not publicly available. This repository only provides analysis code, a variable dictionary, and anonymized example data.
